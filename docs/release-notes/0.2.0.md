## Grabbit 0.2.0

**Fixes YouTube downloads failing with "HTTP Error 403: Forbidden".**

- **Self-updating download engine.** The yt-dlp bundled in 0.1.0 was from November 2025, and YouTube now refuses streams to its out-of-date clients. Grabbit now updates yt-dlp on first launch, once a day in the background and before a download if it's been more than 24 hours. It defaults to the **nightly** channel, where yt-dlp ships YouTube fixes first.
- **Automatic 403 recovery.** If a download is refused, Grabbit updates the engine and retries. On YouTube it then retries once more with alternate player clients. If it still fails you get a plain-English message, not a stack trace.
- **Settings → Download engine** shows the yt-dlp version and when it was last checked. It has an **Update engine now** button and a Nightly/Stable switch.
- **In-app updates.** Grabbit checks this repo's releases on launch (and from **Settings → Check for updates**). It downloads the APK for your phone, verifies its SHA-256 and signing key, then hands it to Android's installer.
- **Plays everywhere.** At each resolution H.264 is now preferred over AV1, so saved videos play on phones without an AV1 decoder.
- Faster repeat YouTube downloads (yt-dlp's cache is kept now). Transient network errors are retried.

**One-time step:** 0.1.0 was signed with a temporary debug key and 0.2.0 uses the permanent release key, so Android can't update from one to the other. **Uninstall 0.1.0, then install 0.2.0.** From then on, updates install in place from inside the app.
